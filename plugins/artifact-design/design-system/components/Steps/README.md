# Steps

Numbered steps for a setup or a recipe, each number in a brush ring that draws itself.

- `<ol class="sk-steps"><li><h4>…</h4><p>…</p></li></ol>`; a code block or figure can follow the text.
- Vertical by default, joined by a hairline; `data-row` lays three or four short steps across (they stack on a phone, and code in them wraps).
