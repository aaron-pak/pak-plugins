# Pills, chips and live tags

- `.sk-pill`: a short status word. `data-tone="good|warn|bad|clay|ink|line|muted"`; `data-dot` adds a dot before it for a status. Putty by default. Always a word, never colour alone, and not on everything.
- `.sk-chip`: a filter you can press (`aria-pressed`), ink when on, with an optional `.sk-count`.
- `.sk-live`: mono uppercase with a clay dot that pulses, for something live. One per page.
