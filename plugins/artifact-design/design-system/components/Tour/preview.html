A plugin for Claude Code

A small band that shows what Claude is doing

session-band sits above the prompt and says what Claude is doing as it reads, thinks, edits and finishes, so you can tell at a glance without reading the log.

Install it
What it shows

One line that changes with the work

> Make the date picker start weeks on Sunday

Read src/picker/day.ts

Edit src/picker/day.ts, 3 lines

Ran bun test picker: 14 passed

Reading src/picker/day.ts Thinking it over Editing src/picker/day.ts Done in 1m 12s · 3 tools · 1 file changed
>
  1. Reading. The band names each file as Claude opens it, so you can see where it is looking.
  2. Thinking it over. A slow pulse between steps, while Claude works out the change. Nothing for you to do yet.
  3. Editing. Each tool gets a few plain words: reading, editing, searching, running the tests.
  4. Done. The band turns clay when the turn lands, with how long it took and what changed, so a glance from across the room is enough.
Set up

Three steps, about a minute

  1. Add the marketplace

    Once per machine.

    claude plugin marketplace add aaron-pak/pak-plugins

  2. Install the plugin

    It turns on in your next session.

    claude plugin install session-band@agent-plugins

  3. Pick a look

    Tide, a little beach, is the default. Hearth is calmer. Change it any time.

    /band hearth
Questions

Before you install

Does it slow Claude down?

No. It reads the same events the terminal already gets and draws one line. It adds no tokens to the conversation.

Does it work in the desktop app?

Yes. The desktop app shows the same band above the prompt, with the pictures drawn in its own style.

How do I turn it off?

Turn it off in /plugin, or uninstall it. To keep it from moving, run /band still.
