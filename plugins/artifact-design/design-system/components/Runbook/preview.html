Reverting

Undo the merge, keep the history

Revert on a branch and merge that, so the red build goes green and anyone reading the log later can see what happened and why.

  1. Find the merge

    git log --merges -n 5 --oneline

  2. Revert it on a branch

    git switch -c revert-red main
git revert -m 1 <merge sha>

  3. Open the pull request

    Title it "Revert" and the original title. Link the red build in the description.

Never

Three things that make it worse

Skipping the failing test

It goes green and the bug ships. Fix it or revert.

Pushing straight to main

Even a one-line fix goes through a pull request, so CI runs on it first.

Waiting it out

A red main blocks everyone. If you can't fix it in 30 minutes, revert.
