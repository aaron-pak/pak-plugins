# Explainer

A whole explainer page built from the parts: a Hero with a hand underline, a Flow with a Note on an oat band, a ringed BigNumber beside a Quote, three drawings on oat and sage panels, and a sage band to close with a Sticky. Copy its structure for a new page.

- `.sk-page` is the column; `.sk-enter` on it plays the entrance once.
- One hero, one quote, one sticky, a note or two. Every section has a drawing or a figure, and prose between them.
- The pace is the point: paper, then the board, then paper, then clay. A page that is read top to bottom should change temperature on the way down.
