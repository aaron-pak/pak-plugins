# Timeline

Events in order, done to next. `data-state="done|now|next|bad"` on each item: done is a filled ink dot, now a clay dot that pulses, next an open ring, bad a red dot.

- Vertical by default (newest first for a log, oldest first for a plan); `data-dir="row"` lays it across for four to six milestones.
- Each item: a `time`, an `h4`, an optional `p`. The line draws itself to "now" when first seen.
