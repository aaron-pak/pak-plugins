Tidybox · for macOS and Linux · free

Tidybox puts your Downloads folder away, and shows you first

One command sorts screenshots, installers and PDFs into folders you already have, and old installers into the Trash. Nothing moves until you say so, and anything can go back.

brew install tidybox
See it run

Look first, then move

A dry run lists what would move and where. Run it again without the flag and it does exactly that, then tells you how to undo it.

Why people keep it

Careful by default

It shows you first

Every run starts as a list. Nothing moves until you run it for real.

It uses your folders

Screenshots go where your screenshots already live. It makes no folders of its own.

Anything can go back

tidybox --undo puts the last run back, for 30 days.

Questions

Before you install

Does it run on its own?

Only if you ask it to. tidybox --every friday adds a weekly run; tidybox --stop removes it.

Can it delete anything?

No. An installer goes to the Trash once it’s 30 days old, where you can still get it back. Nothing is ever deleted outright.

Does it send anything anywhere?

No. It reads file names and types on your computer and nothing else.

Try it

Start with a dry run.

Install it, run tidybox --dry-run in your Downloads folder and read the list. If a rule is wrong, change it before anything moves.

brew install tidybox
