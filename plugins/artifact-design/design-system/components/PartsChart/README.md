# Parts of a whole and sparklines

- `data-sk-chart="stack"`: one rounded bar split into parts, with a legend of names and values under it. Tones of one family by default (clay for the first part, then ink and greys); `data-sk-colors="series"` for the sky, olive and fig set. Largest part first; four parts at most.
- `data-sk-chart="spark"`: a small trend line for a stat, no axes, a clay dot at the end. Data is a plain list of numbers.
