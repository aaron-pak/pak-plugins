# Checkboxes, radios and switches

- `<label class="sk-check"><input type="checkbox"><span>Text<small>detail</small></span></label>`: a white box that fills ink with a brush tick that draws itself.
- `.sk-radio` with `type="radio"`: a ring that fills with an ink dot.
- `.sk-tasks`: a list of checks with an owner pill; done items strike through in muted.
- `<label class="sk-switch"><input type="checkbox" class="sk-toggle" role="switch"> Label</label>`: a switch for a setting that takes effect at once.
