# Comparison matrix

Options across, questions down, a brush mark in each cell.

- `<table class="sk-table sk-matrix">`; `<col class="sk-key">` tints the recommended column clay-soft.
- `<td data-sk-mark="yes|no|part|dot">` draws a tick, a clay cross, a dash or a dot, and adds the word for screen readers. A `small` under it says the catch.
- Rows are the questions that decide it, written as situations ("The house burns down"), not features.
