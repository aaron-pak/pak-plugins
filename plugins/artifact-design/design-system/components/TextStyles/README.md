# Text styles

- `.sk-label`: JetBrains Mono, uppercase, tracked. Above headings and for `dt` terms. The only uppercase text.
- `.sk-h2` (section) and `.sk-h3` (group): Bricolage 600, tight tracking, balanced lines.
- `.sk-prose`: rhythm for long text. Paragraph gaps, clay bullet dots, Bricolage numerals, links in ink with a clay underline that darkens on hover.
- `.sk-dl`: label-and-value pairs, mono terms and ink values on one grid.
- `.sk-small`, `.sk-caption` / `.sk-source`, `kbd`, `code`.
- Running text stays near 66ch (`.sk-measure`).
