# Card

A white card with a hairline border, for one object you could pick up: an option, a result, a person.

- `<article class="sk-card">` with a spot, an `h3`, and any of `.sk-price` (big price, unit in `small`), a paragraph, `.sk-pros` / `.sk-cons` (clay plus and muted minus).
- `data-sk-rec="Our pick"` puts a clay badge on the border and darkens it. One per group.
- An `a.sk-card` or `button.sk-card` lifts 2px on hover.
- Two to four in a `.sk-grid`. A page of nothing but cards reads as an app: keep text and a chart between them.
