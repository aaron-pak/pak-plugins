# Bands

Two quiet sections that run the full width of the page, on the same oat and sage grounds drawings sit on. They give a long page a change of pace, the way a spread does in a magazine.

- `<section class="sk-section" data-mode="band" data-tone="oat">` or `data-tone="sage"`. Use one for the page's main diagram or its idea in one sentence, and one for the thing the page asks for: the ask, the takeaway, the call to action.
- Any part works inside a band. The `em` in a `.sk-statement` stays clay. A sticky note needs sage; on oat it disappears.
- A band is always in the page's own theme. By night it is a deep tint of the same colour with cream type.
- At most two on a page, one of each colour, and never one straight after the other. A band that is the last section runs to the bottom edge.
- The plain `data-mode="band"` with no tone is still there for the softest change of ground.
- In print both bands go back to paper.
