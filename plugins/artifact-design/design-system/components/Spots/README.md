# Spots

The set of drawings, at spot size with putty fills. Point at one to see it redraw.

- `<span class="sk-spot" data-sk-draw="calendar"></span>`, `data-size="s"` (40px) or `"l"` (88px); the default is 64px.
- Beside a feature, an option, a callout or an empty state; one per item, never a row of them as decoration.
- A spot inside a card, callout or option redraws a few frames when you point at the card.
- There are 56; see Drawing for what each one means.
