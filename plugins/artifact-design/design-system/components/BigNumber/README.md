# Big number

One number that is the point of a section: Bricolage 560, tabular, with its unit in `small` and its source or meaning under it.

- `data-size="m"` or `"s"` for smaller. `data-sk-count` counts it up from zero the first time it is seen (only when the text holds one number).
- Always say what it is and where it is from. A big number with no source is decoration.
